### ⚠ The new [Braze Segment Kotlin SDK](https://github.com/braze-inc/braze-segment-kotlin/) is now available! ⚠

> The Braze Segment Android SDK is no longer in active development, since it uses [Analytics-Android](https://github.com/segmentio/analytics-android/blob/master/README.md), which has reached end-of-support in March 2026. We recommend that Braze customers migrate to using the [Braze Segment Kotlin SDK](https://github.com/braze-inc/braze-segment-kotlin), which uses the newer [Analytics-Kotlin](https://github.com/segmentio/analytics-kotlin).

![Braze Logo](https://github.com/braze-inc/braze-android-sdk/blob/master/braze-logo.png)

Braze Android Segment SDK
==========

Braze integration for [analytics-android](https://github.com/segmentio/analytics-android).

If you are using [analytics-kotlin](https://github.com/segmentio/analytics-kotlin), use [braze-segment-kotlin](https://github.com/braze-inc/braze-segment-kotlin) to integrate with Braze.
